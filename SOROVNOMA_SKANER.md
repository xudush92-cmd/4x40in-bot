# SO'ROVNOMA — skanerni takomillashtirish uchun

**Maqsad:** skaner "mijoz izlayotgan odam"ni aniq topishi, haydovchi e'lonlari
va begona ma'lumot o'tib ketmasligi uchun **real bilim** yig'ish.

**Kim to'ldiradi:** botdan foydalanuvchilar (haydovchi/dispetcher) + admin
o'zi. **Muddat:** 5–7 daqiqa. **Hajm:** 10–15 kishi yetarli.

**Nima uchun kerak:** hozir skaner "kalit so'z bor/yo'q" + "emoji bor/yo'q"
darajasida ishlaydi. Bu qo'pol. Sizning real misollaringiz asosida aniqroq
qoidalar (vaznlar, istisnolar, guruhga xos sozlamalar) tuziladi.

> To'ldirish qoidasi: **misollarni so'zma-so'z nusxalab yozing** — tahrir
> qilmang, imlo xatosini ham qoldiring. Aynan xatolar va "dangasa yozuv"
> muhim. Telefon raqamlarini oxirgi 2–3 raqamini `***` bilan yopishingiz
> mumkin.

# NATIJALARNI QANDAY ISHLATAMIZ

| So'rovnoma bo'limi | Nimaga aylanadi |
|---|---|
| 2.1 / 2.5 / 7.2 (o'tkazib yuborilgan misollar) | **Yangi kalit so'zlar** va sinonimlar ro'yxati |
| 2.3 / 2.4 / 7.1 (noto'g'ri o'tgan misollar) | **Manfiy (haydovchi) belgilar** ro'yxati |
| 3.4 jadvali | Har bir so'z uchun **vazn** (+ mijoz / − haydovchi) |
| 3.3 / 3.5 | "Neytral" so'zlar — kalitga **kirmaydi** |
| 4.1–4.7 | **Emoji bosqichini qayta loyihalash** (qat'iy blok → vazn) |
| 5.1–5.5 | **Guruhga xos sozlamalar** va deduplikatsiya qoidasi |
| 6.3 / 6.4 / 8.4 | **Bildirishnoma chegarasi** (kuniga limit, prioritet) |
| 7.3 / 7.4 | Filtrning **qaysi bosqichi** aybdorligini aniqlash |
| 8.1–8.3 | Keyingi versiya rejasi |

**Yig'ilgandan keyin qilinadigan ish (tartib bilan):**

1. Barcha misollar bitta faylga yig'iladi: `mijoz` / `haydovchi` / `aloqasiz`.
2. Har bir misol **hozirgi** filtrdan o'tkaziladi — qaysi bosqichda to'xtagan
   yoki o'tib ketgan yoziladi.
3. Xatolar ikki guruhga bo'linadi: **noto'g'ri o'tgan** va **o'tkazib
   yuborilgan**. Har biriga sabab yoziladi.
4. Kalit so'zlar ro'yxati qayta ko'riladi: ortiqcha so'zlar chiqariladi,
   yetishmayotgan o'zaklar qo'shiladi.
5. Vaznli skoring sinovdan o'tkaziladi: `mijoz topish %` va
   `haydovchi o'tib ketish %` solishtiriladi. **Maqsad:** mijoz ≥ 90%,
   haydovchi ≤ 5%.
6. Faqat shundan keyin kodga tegadi (har bir o'zgarish alohida commit va
   test bilan).

# ESLATMA (javob beruvchiga)

- Bu so'rovnoma **majburiy emas**, lekin qancha ko'p real misol bo'lsa,
  bot shuncha aniq ishlaydi.
- **Maxfiy ma'lumot kerak emas**: parol, kod, sessiya, to'liq telefon raqami
  so'ralmaydi.
- Misollarni **o'zgartirmasdan** yozing — imlo xatosi ham foydali.
- Javobni **bir marta** yuboring, to'liq bo'lishi shart emas — qaysi
  savolga javob bilsangiz, o'shanga yozing.
