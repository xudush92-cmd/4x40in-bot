# Kiro uchun ishlash qoidalari

## 1. Kod o'zgartirish
- Foydalanuvchining RUXSATISIZ hech qanday kod yozma yoki o'zgartirma.
- Har qanday kod o'zgarishidan oldin foydalanuvchidan aniq tasdiq so'ra.
- Yangi kod yozishdan ko'ra, mavjud kodni MINIMAL to'g'rilashni afzal ko'r.

## 2. Git / PR
- Yangi PR yoki branch OCHMA.
- Faqat mavjud branch ustida ishla, har safar yangi branch/PR yaratma.
